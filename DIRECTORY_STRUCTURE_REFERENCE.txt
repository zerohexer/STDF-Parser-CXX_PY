┌──────────────────────────────────────────────────────────────────────────────┐
│ RECOMMENDED DIRECTORY HIERARCHY                                              │
└──────────────────────────────────────────────────────────────────────────────┘

/data/stdf-ingestion/
│
├─ incoming/                    ◄── WATCHDOG MONITORS HERE
│  └─ {FACILITY}/               (Level 1: Testing site, e.g., "OSBE25", "OSBE26")
│     └─ {LOT}/                 (Level 2: Production lot, e.g., "KEWGBCLD1U")
│        └─ {PRODUCT}/          (Level 3: Device/Product, e.g., "BE_HRG3301Y.06")
│           └─ {TEST_PROGRAM}/  (Level 4: Test program, e.g., "Prod_TPP202_03")
│              └─ *.stdf        ◄── DROP FILES HERE
│
├─ processing/                  ◄── FILES BEING PROCESSED
│  └─ {same hierarchy as incoming}
│
├─ processed/                   ◄── SUCCESSFULLY INGESTED
│  └─ {FACILITY}/
│     └─ {LOT}/
│        └─ {PRODUCT}/
│           └─ {TEST_PROGRAM}/
│              └─ {YYYY}/       (Year, e.g., "2025")
│                 └─ {MM}/      (Month, e.g., "11")
│                    └─ {DD}/   (Day, e.g., "24")
│                       └─ *.stdf
│
└─ failed/                      ◄── PROCESSING ERRORS
   └─ {same hierarchy as incoming}
      ├─ *.stdf                 (Failed file)
      └─ *.error.log            (Error details)

┌──────────────────────────────────────────────────────────────────────────────┐
│ FIELD MAPPINGS TO DATABASE                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

Directory Level          Database Field         Example Value
───────────────          ──────────────         ─────────────
FACILITY             →   wfi_facility           "OSBE25"

Note: STDF file headers contain the authoritative metadata. Directory structure
      is for organization only. Parser extracts all fields from STDF records.

┌──────────────────────────────────────────────────────────────────────────────┐
│ QUICK COMMANDS                                                               │
└──────────────────────────────────────────────────────────────────────────────┘

Setup directories:
  python3 setup_ingestion_dirs.py --facilities OSBE25 OSBE26

Start watchdog:
  python3 watchdog_ingestion.py

Copy file for processing:
  cp test.stdf /data/stdf-ingestion/incoming/OSBE25/LOT001/PRODUCT/TEST_V1/

Monitor logs:
  tail -f stdf_ingestion.log

Check status:
  find /data/stdf-ingestion/incoming -name "*.stdf" | wc -l     # Pending
  find /data/stdf-ingestion/processing -name "*.stdf" | wc -l   # In progress
  find /data/stdf-ingestion/processed -name "*.stdf" | wc -l    # Completed
  find /data/stdf-ingestion/failed -name "*.stdf" | wc -l       # Failed

View failed file errors:
  cat /data/stdf-ingestion/failed/OSBE25/.../file.error.log


┌──────────────────────────────────────────────────────────────────────────────┐
│ FLEXIBILITY & OPTIONS                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

✓ You DON'T need all 4 levels - use any depth that fits your workflow
✓ Directory names are flexible - use your own conventions
✓ Supports spaces and special characters in names
✓ Recursive monitoring - automatically creates missing parent directories
✓ File naming is up to you - only .stdf extension matters
✓ STDF header metadata always takes precedence over directory names


┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

Files not processing?
  → Check watchdog is running: ps aux | grep watchdog
  → Check file permissions: ls -la /data/stdf-ingestion/incoming/
  → Verify .stdf extension (case-insensitive)
  → Review logs: tail -f stdf_ingestion.log

ClickHouse errors?
  → Test connection: clickhouse-client --query "SELECT 1"
  → Check host/port in command arguments
  → Verify tables exist: clickhouse-client --query "SHOW TABLES"

Files stuck in processing?
  → Check logs for errors
  → Manually move back to incoming/ or to failed/
  → Restart watchdog service
